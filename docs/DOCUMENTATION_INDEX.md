## 🎯 Documentation Guidelines

### When Creating New Docs

1. **Add to this index** - Update relevant sections
2. **Link related docs** - Cross-reference related topics
3. **Use clear titles** - Descriptive and searchable
4. **Include date** - When doc was created/updated
5. **Add status** - Draft, Complete, Deprecated

### Document Naming

- **Features:** `FEATURE_NAME_GUIDE.md` (user) + `FEATURE_NAME_SUMMARY.md` (quick ref)
- **Fixes:** `FIX_ISSUE_DESCRIPTION.md`
- **Technical:** `TECHNICAL_TOPIC.md`
- **Planning:** `PLANNING_TOPIC.md`

### Document Structure

```markdown
# Title

**Date:** YYYY-MM-DD
**Status:** Complete/Draft/Deprecated

## Overview
Brief description

## Details
Main content

## Summary
Key takeaways
```
