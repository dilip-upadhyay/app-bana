| Duplicate Selected Node | Cmd+D | Ctrl+D | Duplicate | Duplicates selected subtree as sibling (root not duplicated) |

## Duplicate Behavior Details
- Entire subtree of the selected node is cloned.
- All cloned node IDs are generated by appending `-copy`, with numeric suffixes (`-copy-1`, `-copy-2`, …) to ensure uniqueness.
- Inserted immediately after original in parent children array.
- Selection moves to new subtree root.
- Undo removes the clone; Redo restores it with same IDs.

## Delete Behavior
- Press Backspace/Delete to remove selected node.
- If the node has children a confirm dialog protects against accidental subtree removal.
- Root node is protected.

## Search / Navigate Palette (Cmd/Ctrl+P)
- Fuzzy-style filter (substring match) on ID, type, or text prop.
- Arrow Up/Down to navigate results; Enter to select; Esc to close.
- Limited to first 50 matches for performance.

## Copy ID (Shift+Cmd/Ctrl+C)
- Copies current selection ID to clipboard (if supported) and shows a transient toast.
- Gracefully degrades if clipboard API unavailable.

## Inline Text Editing (Enter)
- Select a `text` node and press Enter to edit its `text` prop inline.
- Enter (while editing) or blur commits changes; Esc cancels.
- Undo/redo tracks the prop update.

## Drag & Drop Reorder / Reparent
- Drag a non-root node onto a `container` node to reparent; it becomes the last child.
- Cycle prevention enforced by underlying `TreeStore.moveNode`.
- Visual indicator: dashed outline on valid drop target.

## Expand / Collapse & Persistence
- Each node with children shows a disclosure control (▸ / ▾).
- Expanded node IDs are persisted per page under `studio.expanded.<pageId>` in localStorage.
- Root auto-expanded by default when no prior state exists.
