# UI Builder Shortcuts & Actions

This quick reference lists currently implemented productivity shortcuts in the Studio Builder.

| Action | Shortcut (macOS) | Shortcut (Windows/Linux) | Toolbar Button | Notes |
|--------|------------------|---------------------------|----------------|-------|
| Undo | Cmd+Z | Ctrl+Z | Undo | Multi-step history (limited by store historyLimit, default 100) |
| Redo | Shift+Cmd+Z or Cmd+Y | Ctrl+Y | Redo | Redo stack cleared on new mutation |
| Duplicate Selected Node | Cmd+D | Ctrl+D | Duplicate | Duplicates the selected subtree as a sibling right after original (root not duplicated) |
| Delete Node | (no shortcut yet) | (no shortcut yet) | × on node | Not available for root |
| Add Child Text Node | (no shortcut yet) | (no shortcut yet) | + on node | Inserts a new text node under target |

## Duplicate Behavior Details
- Entire subtree of the selected node is cloned.
- All cloned node IDs are generated by appending `-copy`, with numeric suffixes (`-copy-1`, `-copy-2`, …) to ensure uniqueness.
- The cloned root of the subtree is inserted immediately after the original within the parent’s children array.
- After duplication, selection automatically moves to the new subtree root.
- Undo removes the cloned subtree; Redo restores it with the same generated IDs.

## Contributing New Shortcuts
1. Add key handling in `BuilderCanvas` (`onKeyDown`).
2. Gate by selection state or store availability.
3. Provide accessible toolbar fallback.
4. Add/update tests in `TreeStore.*.test.ts` or a new UI interaction test harness (future for component-level testing).
